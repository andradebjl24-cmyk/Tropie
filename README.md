# 🌴 Tropie

Landing page responsiva desenvolvida com **HTML, CSS e JavaScript**.

## 📌 Sobre o projeto

O **Tropie** é uma landing page criada para praticar desenvolvimento web, trabalhando estrutura de páginas, estilização, responsividade e interações com JavaScript.

## 🚀 Tecnologias

* HTML5
* CSS3
* JavaScript
* Git
* GitHub
* Vercel

## 📂 Estrutura do projeto

```text
Tropie/
├── index.html
├── style.css
└── script.js
```

## 🌐 Projeto online

**Acesse:** https://tropie.vercel.app/

## 💻 Como executar localmente

Clone o repositório:

```bash
git clone https://github.com/andradebjl24-cmyk/Tropie.git
```

Entre na pasta:

```bash
cd Tropie
```

Depois, abra o arquivo `index.html` no navegador.

## 🎯 Objetivo

O projeto foi desenvolvido como parte da minha prática em desenvolvimento web, colocando em prática conhecimentos de **HTML, CSS e JavaScript**, além do uso de **GitHub e Vercel** para versionamento e publicação.
